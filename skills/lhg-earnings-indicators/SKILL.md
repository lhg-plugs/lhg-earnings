# lhg-earnings-indicators：核心指标计算手册

> **合规声明（红线，先读）**：数据源短板——本手册依赖用户提供或公开数据快照，
> 非实时行情；本 skill 仅做财务数据解读教育，不构成投资建议。
> 输出中绝不出现买入/卖出/目标价等投顾表述。

> 目标：算对。财报解读里 90% 的"翻车"不是观点错了，是指标算错了——
> 口径混了、单位错了、分子分母对不上。本手册把每个指标的公式和坑一次讲清。

## 1. 何时使用

- 算任何财报指标之前 → 先查本手册确认公式与口径
- 审计脚本报"公式复算偏差"时 → 来这里找口径不一致的原因
- 用户问"这个指标是什么意思"时 → 用第 3 节的"一句话人话"解释

## 2. 计算总纪律

1. **先定口径，再动手**：每个指标先写清"分子是什么、分母是什么"，再计算
2. **单位全文统一**：万元和亿元混用是最高发的错误，计算前先统一
3. **季报不年化**：单季 ROE 直接用单季净利润算，标注"单季、未年化"；要年化必须写清方法
4. **偏差超 1 个百分点先对账**：复算对不上，第一反应是"口径错了"，不是"脚本错了"

## 3. 盈利能力指标

### 3.1 毛利率 =（营收 - 营业成本）/ 营收 × 100%

- **人话**：卖 100 块的货，扣掉直接成本还剩多少
- **口径坑**：制造业的"营业成本"不含期间费用；别把销售费用减进去算"毛利"
- **看什么**：趋势比绝对值重要。连续下滑 3 个百分点以上，去看是价格战还是成本涨

### 3.2 净利率 = 净利润 / 营收 × 100%

- **人话**：卖 100 块，最后真正落袋多少
- **口径坑**：归母净利润 vs 扣非净利润。解读主业成色用**扣非**，看股东回报用归母，两个都算、都标注
- **看什么**：净利率 - 毛利率的差，反映费用控制能力

### 3.3 ROE = 净利润 / 净资产 × 100%

- **人话**：股东投 100 块，一年赚回来多少
- **口径坑**：简易口径用期末净资产；严谨口径用（期初+期末）/2。两种都行，但必须写清用的是哪种
- **看什么**：ROE 高要拆——是赚得多（净利率高），还是转得快（周转高），还是借得多（杠杆高）

### 3.4 ROA = 净利润 / 总资产 × 100%

- **人话**：全部资产（含借来的）一年赚回来多少
- **口径坑**：分母是总资产不是净资产，别和 ROE 搞混

### 3.5 杜邦拆解（ROE 的"验钞机"）

ROE = 净利率 × 总资产周转率 × 权益乘数

- 净利率高 → 靠产品赚钱（好）
- 周转率高 → 靠效率赚钱（好）
- 权益乘数高 → 靠借钱撑 ROE（警惕：杠杆越高，ROE 越虚）

## 4. 偿债与杠杆指标

### 4.1 资产负债率 = 总负债 / 总资产 × 100%

- **人话**：100 块资产里有多少是借来的
- **阈值**：> 70% 为高杠杆预警线（本插件审计规则 E-RISK-001）
- **口径坑**：先看行业——银行、地产天然高杠杆，不能一刀切；再看有息负债占比

### 4.2 流动比率 = 流动资产 / 流动负债

- **人话**：一年内能变现的钱，够不够还一年内到期的债
- **看什么**：< 1 要警惕短期偿债压力；> 3 要看是不是资金利用效率太低

### 4.3 速动比率 =（流动资产 - 存货）/ 流动负债

- **人话**：把最难卖的存货扣掉，还够不够还债
- **口径坑**：存货占比高的行业（地产、制造），流动比率和速动比率差很多，两个都要看

### 4.4 利息保障倍数 = 息税前利润 / 利息费用

- **人话**：赚的钱够付几次利息
- **看什么**：< 2 说明利息压力大；为负说明主业已经覆盖不了利息

## 5. 现金流指标

### 5.1 经营现金流净额（直接取数，不计算）

- **人话**：本业一年真金白银进账多少
- **铁律**：利润表可以靠会计估计调节，现金流是试金石

### 5.2 现金流利润比 = 经营现金流 / 净利润

- **人话**：账面利润里有多少是真钱
- **红灯**：净利润为正、经营现金流为负 → 现金流背离（本插件审计规则 E-RISK-003，blocker 级）
- **看什么**：长期 < 1 说明利润质量差，钱没收回来

### 5.3 自由现金流 = 经营现金流 - 资本开支

- **人话**：维持和扩张生产花完之后，还剩多少真钱
- **口径坑**：资本开支取现金流量表"购建固定资产等支付的现金"，别用资产负债表倒轧

## 6. 运营质量指标

### 6.1 应收账款周转天数 = 365 /（营收 / 平均应收账款）

- **人话**：货卖出去平均多少天能收回钱
- **红灯**：应收增速 - 营收增速 > 20 个百分点 → 应收暴涨（E-RISK-005）

### 6.2 存货周转天数 = 365 /（营业成本 / 平均存货）

- **人话**：货在仓库里平均躺多少天
- **红灯**：存货增速 - 营收增速 > 20 个百分点 → 存货积压（E-RISK-006）

### 6.3 商誉 / 净资产

- **人话**：净资产里有多少是并购时多付的"空气"
- **红灯**：> 30% → 商誉减值风险（E-RISK-004）；必须去看并购标的业绩承诺完成情况

## 7. 成长指标

### 7.1 营收增速 =（本期营收 - 上年同期营收）/ |上年同期营收| × 100%

- **口径坑**：同比（vs 上年同期）消除季节性；环比（vs 上一期）看短期动量。两个都算、都标注
- **红灯**：|增速| > 50% → 先排除并购/剥离/会计政策变更（E-TREND-001）

### 7.2 净利润增速（同公式，分母用净利润）

- **口径坑**：基数太小或为负时增速失真——上年亏 1 万、今年赚 1 万，增速写法是"扭亏为盈"，不许写"+200%"
- **红灯**：|增速| > 100% 或盈亏互转 → 拆扣非净利润看主业（E-TREND-002）

## 8. 指标速查表

| 指标 | 公式 | 红灯线 |
|---|---|---|
| 毛利率 | （营收-成本）/营收 | 同比下滑 > 5pt |
| 净利率 | 净利润/营收 | 长期 < 5% 看行业 |
| ROE | 净利润/净资产 | 靠杠杆撑起来的要警惕 |
| 资产负债率 | 总负债/总资产 | > 70% |
| 现金流利润比 | 经营现金流/净利润 | < 0（背离） |
| 商誉/净资产 | 商誉/净资产 | > 30% |
| 应收增速-营收增速 | 差值 | > 20pt |
| 存货增速-营收增速 | 差值 | > 20pt |

## 9. 反模式（不要这么做）

- ❌ 归母和扣非混着用——两个都算，标注清楚
- ❌ 季报 ROE 直接当成年化——要么标注"单季"，要么写清年化方法
- ❌ 分母为负时还硬算比率——净资产为负时 ROE 没有意义，写"不适用"并解释原因
- ❌ 只给结论不给公式——每个指标第一次出现时写一遍公式，让读者能复算

## 10. 自检与反馈

每次执行完本 skill，做一次轻量自检（不额外输出打扰用户）：

1. 每个指标是否写清了分子分母口径？→ 没写就补上。
2. 有没有出现单位混用？→ 统一单位后重算。
3. 复算偏差超 1 个百分点时，有没有先对账而不是硬解释？→ 有就回头对账。
4. 输出里有没有出现投顾表述？→ 有就删掉。

如发现本 skill 自身的方法论缺陷，按以下流程反馈：

- **标准冒烟用例**：用 `fixtures/report-good/data.json` 的三期数据，
  手工复算毛利率/净利率/ROE/资产负债率，与 `computed` 字段对比，
  偏差应 < 0.1 个百分点；再故意改错一个数，审计脚本应报 E-CALC-*。
- **一键提 issue**：确认问题后，以 `[QC] <一句话问题>` 为标题、
  正文写清"复现输入 → 错误输出 → 期望输出"，提交到
  https://github.com/lhg-plugs/lhg-earnings/issues。

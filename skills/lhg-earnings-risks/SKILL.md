# lhg-earnings-risks：风险点扫描手册

> **合规声明（红线，先读）**：数据源短板——本手册依赖用户提供或公开数据快照，
> 非实时行情；本 skill 仅做财务数据解读教育，不构成投资建议。
> 输出中绝不出现买入/卖出/目标价等投顾表述。

> 目标：把财报里的"雷"一个一个找出来。看财报不是看公司多好，
> 是看哪里不对劲——好公司也会藏雷，差公司的雷都写在明面上。
> 核心纪律：**每个风险写三段式——现象（数字）→ 可能的原因（2-3 种）→ 待验证（去哪找证据）。**

## 1. 何时使用

- 解读报告写到"风险清单"章节时 → 按第 3 节逐项扫描
- 用户问"这家公司有没有雷"时 → 先跑审计脚本，再用本手册解读每条发现
- 审计脚本报 E-RISK-* 时 → 来这里找"这个风险意味着什么、接下来看什么"

## 2. 扫描总纪律

1. **数字先行**：每条风险第一句必须是数字，不许先下结论再找数字
2. **原因给多个**：每个现象至少列 2 种可能原因，不许只给一种（单一归因是解读的大忌）
3. **结论留验证口**：每条风险结尾写"待验证：去财报附注/公告里找 XX"
4. **不许轻描淡写**：现金流背离这种红灯必须放风险清单首位，不许藏在中间

## 3. 十大风险清单

### 风险 1：现金流背离（最高优先级）

- **现象**：净利润为正，经营现金流为负（审计规则 E-RISK-003，blocker 级）
- **人话**：账上说赚了，口袋里是空的
- **可能的原因**：
  1. 应收账款积压：货发出去了，钱没收回来（去看风险 4）
  2. 存货积压：生产了没卖掉，现金沉淀在仓库（去看风险 5）
  3. 激进的收入确认：提前确认收入，现金还没到（去看收入确认政策）
- **待验证**：现金流量表附注"净利润调节为经营现金流"表，看是哪一项吞掉了利润

### 风险 2：高杠杆

- **现象**：资产负债率 > 70%（E-RISK-001）
- **人话**：100 块资产里 70 块以上是借来的
- **可能的原因**：
  1. 行业属性：银行、地产、建筑天然高杠杆，先看行业再下判断
  2. 激进扩张：借钱并购/扩产，赌未来现金流覆盖
  3. 借新还旧：经营现金流覆盖不了到期债务
- **待验证**：有息负债占比、利息保障倍数、一年内到期债务 vs 货币资金

### 风险 3：商誉高企

- **现象**：商誉 / 净资产 > 30%（E-RISK-004）
- **人话**：净资产里三成是并购时多付的"空气"
- **可能的原因**：
  1. 高溢价并购：买贵了，业绩承诺一旦完不成就是减值
  2. 并购标的业绩变脸：被并购公司增长失速
  3. 减值测试偏乐观：管理层用乐观假设"保住"商誉账面值
- **待验证**：并购标的的业绩承诺完成情况、商誉减值测试的关键假设（折现率、增长率）

### 风险 4：应收账款暴涨

- **现象**：应收增速 - 营收增速 > 20 个百分点（E-RISK-005）
- **人话**：收入涨 10%，应收涨 50%——钱没收回来，收入先记上了
- **可能的原因**：
  1. 放宽信用政策冲收入：年底压货给经销商
  2. 下游客户出问题：客户没钱付，账期被动拉长
  3. 收入确认激进：货没发全就确认收入
- **待验证**：应收账款账龄结构、坏账计提比例、前五大客户集中度

### 风险 5：存货积压

- **现象**：存货增速 - 营收增速 > 20 个百分点（E-RISK-006）
- **人话**：货越囤越多，卖得越来越慢
- **可能的原因**：
  1. 备货赌行情：管理层判断涨价/旺季，提前备货（可能是对的）
  2. 产品滞销：卖不动了，只能囤着
  3. 跌价风险：存货跌价准备计提不足，利润里藏着未来的减值
- **待验证**：存货跌价准备计提比例、库龄结构、期后销售情况

### 风险 6：毛利率塌方

- **现象**：毛利率同比下滑 > 5 个百分点（E-RISK-007）
- **人话**：卖 100 块能剩的钱，突然少了 5 块以上
- **可能的原因**：
  1. 价格战：降价保份额，收入端失血
  2. 成本上涨：原材料/人工涨价，成本端失血
  3. 产品结构变化：低毛利产品占比上升
- **待验证**：分产品毛利率、主要原材料价格走势、销售费用是否同步上升（降价促销的痕迹）

### 风险 7：经营现金流为负

- **现象**：经营现金流净额 < 0（E-RISK-002）
- **人话**：主业一年下来，现金是净流出的
- **可能的原因**：
  1. 扩张性投入：主动囤货、扩产，现金换成了资产（中性偏好）
  2. 回款恶化：客户拖款，被动失血（危险）
  3. 补贴/垫资模式：靠垫资拿订单，规模越大失血越多
- **待验证**：结合风险 1、4、5 一起看——单看为负不可怕，可怕的是不知道钱去哪了

### 风险 8：利润剧烈波动

- **现象**：净利润同比增速 |超过| 100%，或盈亏互转（E-TREND-002）
- **人话**：利润一年翻几倍、下一年又亏回去——这种利润不叫增长，叫波动
- **可能的原因**：
  1. 非经常性损益：卖资产、政府补助、公允价值变动
  2. 一次性减值：商誉/存货/应收集中计提
  3. 周期行业：本身就是强周期，利润随价格波动
- **待验证**：扣非净利润的增速——把"水分"挤掉，看主业的真实体温

### 风险 9：营收异常波动

- **现象**：营收同比增速 |超过| 50%（E-TREND-001）
- **人话**：一年涨/跌一半以上，先别急着夸或骂
- **可能的原因**：
  1. 并购/剥离：报表合并范围变了，不是内生增长
  2. 会计政策变更：收入确认时点变了
  3. 大客户依赖：单一大客户订单波动传导到报表
- **待验证**：剔除并购影响后的内生增速、前五大客户收入占比

### 风险 10：数据缺失本身

- **现象**：关键字段缺失（E-DATA-003/004），或数据来源未声明（E-DATA-005）
- **人话**：看不见的风险也是风险——缺现金流量表，就别谈现金流结论
- **纪律**：缺什么写什么，不许脑补；报告里明确标注「缺数据」的章节，结论降级为"无法判断"

## 4. 风险组合：1+1 > 2

单个风险可能是偶然，组合出现就要高度警惕：

| 组合 | 意味着什么 |
|---|---|
| 现金流背离 + 应收暴涨 | 收入很可能是"纸面富贵"，钱没收回来 |
| 高杠杆 + 经营现金流为负 | 借的钱还不上，债务风险 |
| 商誉高企 + 利润下滑 | 商誉减值暴雷的前兆组合 |
| 存货积压 + 毛利率塌方 | 产品卖不动还得降价，竞争力出问题 |
| 利润暴涨 + 扣非很平 | 增长来自非经常性损益，不可持续 |

## 5. 风险清单写作模板

每条风险按这个模板写，不许自由发挥：

```
### 风险 N：<风险名>（<风险等级：红灯/黄灯>）

- **现象**：<数字，精确到小数点后一位>
- **可能的原因**：<2-3 种，编号列出>
- **待验证**：<去财报附注/公告里找什么，具体到科目或章节>
```

## 6. 反模式（不要这么做）

- ❌ 只列现象不给验证路径——读者看完还是不知道去哪求证
- ❌ 把"风险提示"写成"公司经营存在一定不确定性"这种正确的废话
- ❌ 用单一原因解释所有风险——"都是行业不好"不是分析，是偷懒
- ❌ 风险清单藏在报告中间——红灯风险必须放首位，一眼能看到

## 7. 自检与反馈

每次执行完本 skill，做一次轻量自检（不额外输出打扰用户）：

1. 每条风险有没有写数字？→ 没写数字的删掉重写。
2. 每条风险有没有给 2 种以上可能原因？→ 只有一种的补上。
3. 现金流背离有没有放首位？→ 没有就调整顺序。
4. 输出里有没有出现投顾表述？→ 有就删掉。

如发现本 skill 自身的方法论缺陷，按以下流程反馈：

- **标准冒烟用例**：用 `fixtures/report-bad/data.json` 跑审计脚本，
  对每条 E-RISK-* 发现用本手册写出"现象→原因→待验证"三段式，
  检查是否覆盖了现金流背离/高杠杆/商誉/应收/存货/毛利率全部六类。
- **一键提 issue**：确认问题后，以 `[QC] <一句话问题>` 为标题、
  正文写清"复现输入 → 错误输出 → 期望输出"，提交到
  https://github.com/lhg-plugs/lhg-earnings/issues。

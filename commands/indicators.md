# /lhg-earnings:indicators —— 指标速算

用户输入在 `$ARGUMENTS` 中：`data.json` 路径，或直接粘贴的关键数据（营收、成本、利润、资产、负债等）。

## 流程

### 1. 整理输入

- 确认单位统一、报告期明确
- 口径先行：净利率用归母还是扣非？ROE 用期末还是平均净资产？先写清再算
- 口径查 skill `lhg-earnings-indicators` 第 2 节

### 2. 计算（用脚本，不许心算）

把数据整理成 `data.json` 后跑审计脚本的公式复算：

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/earnings_audit.py --target <数据目录> --format text
```

脚本自动复算毛利率 / 净利率 / ROE / 资产负债率（规则 E-CALC-001~004），
偏差 > 1 个百分点会报警。

### 3. 输出指标表

| 指标 | 本期 | 上年同期 | 变化 |
|---|---|---|---|
| 毛利率 | … | … | … |
| 净利率（扣非） | … | … | … |
| ROE | … | … | … |
| 资产负债率 | … | … | … |
| 经营现金流 | … | … | … |
| 现金流利润比 | … | … | … |

每个指标第一次出现时写一遍公式；算不出来的写「缺数据」。

### 4. 一句话解读（只讲事实）

- 每个指标配一句"数字先行"的事实描述，如"毛利率 37.6%，同比基本持平"
- 不许出现"值得买入""估值便宜"等表述（查 `lhg-earnings-compliance` 黑名单）

## 硬规则

- 心算指标 → 不许，走脚本。
- 复算偏差超 1 个百分点还硬解释 → 不许，先对账。
- 输出投顾表述 → 不许。

# /lhg-earnings:risks —— 风险扫描

用户输入在 `$ARGUMENTS` 中：含 `data.json` 的数据目录路径。

## 流程

### 1. 跑审计脚本

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/earnings_audit.py --target <数据目录> --format text
```

记下所有 E-RISK-* / E-TREND-* 发现（含阈值、涉及的报告期）。

### 2. 分级

- **红灯**（blocker）：现金流背离（E-RISK-003）→ 必须放清单首位
- **黄灯**（warning）：高杠杆、商誉、应收暴涨、存货积压、毛利率塌方、现金流为负等
- **灰灯**（nit）：单期数据无趋势等 → 备注说明，不展开

### 3. 逐条解读

按 skill `lhg-earnings-risks` 第 3 节，每条风险写三段式：

```
### 风险 N：<风险名>（红灯/黄灯）

- **现象**：<数字>
- **可能的原因**：<2-3 种>
- **待验证**：<去财报附注/公告里找什么>
```

### 4. 风险组合检查

按 `lhg-earnings-risks` 第 4 节检查组合：
现金流背离+应收暴涨、高杠杆+现金流为负、商誉高企+利润下滑——
组合出现要单独拎出来强调。

## 硬规则

- 只列现象不给验证路径 → 不许。
- 把红灯风险藏在清单中间 → 不许，现金流背离必须首位。
- 借风险清单输出买卖建议 → 不许，这是红线。
